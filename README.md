# AttendanceOS — Smart Attendance Management Dashboard

A modern attendance and internal marks management dashboard built using HTML, CSS, JavaScript, and Firebase Realtime Database.

## 🚀 Features

- Real-time attendance tracking
- Internal marks management (0–5)
- Firebase Realtime Database integration
- CSV export functionality
- Live statistics dashboard
- Responsive dark-themed UI
- Dynamic attendance summaries

## 🛠 Tech Stack

- HTML5
- CSS3
- JavaScript
- Firebase Realtime Database

## 📌 Functionalities

- Mark students present/absent
- Assign internal marks
- Export attendance data as CSV
- Store attendance records in Firebase
- Real-time statistics calculation

## 🔮 Future Improvements

- Authentication system
- Teacher/Admin roles
- Student analytics dashboard
- Search and filtering system
- Cloud deployment enhancements
